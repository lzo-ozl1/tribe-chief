# 부족장 (Tribe Chief) — Game Design

## 1. 프로젝트 개요
- 장르: 선사시대 부족 경쟁 전략 게임
- 플레이어: 2–6명
- 목표 점수: 15점
- 핵심 루프: 자원 획득 → 상대 견제/방어 → 점수 카드 구매 → 부족장 보너스
- 개발 목표: PC 브라우저에서 규칙을 검증한 뒤 모바일(iOS/Android)로 확장

## 2. 기본 자원
| 자원 | 기호 | 역할 |
|---|---|---|
| 불 | 🔥 | 공격 |
| 물 | 💧 | 나무 방어 |
| 돌 | 🪨 | 식량 방어 |
| 나무 | 🪵 | 카드 구매 / 가축 유지 |
| 식량 | 🌾 | 카드 구매 / 가축 유지 |

특수 자원: 🐄 가축
- 가축 1개 = 카드 구매 시 범용 자원 2개 가치
- 단, 한 장의 점수 카드 구매에 사용할 수 있는 가축은 최대 1개
- 베타 기본 규칙: 가축 1개로 인쇄된 비용의 같은 종류 2개 또는 서로 다른 종류 1개씩을 대체할 수 있다.
- 대체 비용의 합계는 정확히 2개이며, 카드에 없는 비용을 대체하거나 초과 지불하지 않는다.
- 비교용 제한 모드에서는 같은 종류 2개만 대체한다. 테스트 결과에 따라 최종 규칙을 결정한다.
- 가축 수는 항상 공개

## 3. 공개·은닉 자원
- 기본 자원은 종류별로 공개분과 은닉분을 구분한다.
- 획득 시 공개한 토큰은 사용·손실·폐기될 때까지 계속 공개 상태를 유지한다.
- 상대에게 공개분의 종류별 수량, 은닉 토큰 총개수, 가축 수, 전체 토큰 수를 보여준다.
- 은닉분의 종류별 수량은 소유자만 확인한다.
- 같은 종류를 나중에 공개 획득해도 이전 은닉분은 공개로 바뀌지 않는다.
- 구매·공격 피해·한도 초과 폐기 등 모든 차감은 해당 종류의 공개분부터 처리하고, 부족한 만큼 은닉분에서 처리한다.
- 버릴 종류는 플레이어가 선택하되 공개/은닉 중 어느 쪽을 쓸지는 선택하지 않는다.
- 가축은 항상 공개한다.
- 은닉 보유량에 별도 한도는 없다. 은닉 10개 이상도 허용하며 턴 종료 시 전체 토큰 15개 한도만 적용한다.

## 4. 턴 시작 자원 획득
턴 시작 시 다음 중 하나를 선택한다.

### 선택 A — 서로 다른 기본 자원 3개
- 기본 자원 중 서로 다른 3개를 자유롭게 선택
- 가져온 3종 중 서로 다른 2종을 선택하여 공개
- 공개한 2개는 공개 재고, 나머지 1개는 은닉 재고에 추가한다.

### 선택 B — 같은 기본 자원 2개 + 가축 1개
- 기본 자원 종류는 자유롭게 선택
- 기본 자원 2개 모두 공개 재고에 추가한다.
- 가축 1개 획득(항상 공개)

## 5. 보유 한도
- 기본 자원 + 가축을 합산한 총 보유량의 한도는 턴 종료 시 15개이다.
- 턴 중에는 15개 초과 보유를 허용한다. 보유량이 15개인 상태에서 턴 시작 자원 3개를 획득하면 18개가 된다.
- 턴 중 자원을 사용한 뒤, 턴 종료 시에도 15개를 초과하면 플레이어가 초과 수량만큼 버릴 토큰을 선택해 15개로 맞춘다.
- 턴 종료 시 이미 15개 이하라면 버릴 필요가 없다.
- 가축 1개는 보유량 계산에서 토큰 1개로 센다.

## 6. 공격 / 방어
### 기본 규칙
- 공격은 공격자의 턴 시작 즉시, 자원 획득 전에 실행
- 일반 공격은 한 턴 최대 1회이며, 공격 스킬의 사용 횟수와 별개다.
- 공격 대상은 공격자가 선택
- 공격 자원: 불(1개 이상 보유해야 선언 가능)
- 공격 사실, 공격자, 방어자, 지정 자원과 결과는 모두 공개한다.
- 공개 불이 있으면 그것으로 공격한다. 은닉 불을 사용해 공격 성공·무효로 불이 남으면 1개를 공개 재고로 전환한다. 방어에 막히면 사용한 불 1개는 소모되며 다른 은닉 불을 공개하지 않는다.
- 물·돌에 의한 기본 방어는 공개·은닉 보유량을 합산하여 자동 처리한다.
- 해당 방어 토큰이 이미 공개되어 있으면 그것으로 방어한다. 공개분 없이 은닉 물·돌로 방어하면 1개를 공개 재고로 전환한다. 방어 토큰은 소모하지 않는다.
- 대상 자원이 없으면 다른 자원으로 전환하지 않는다. 일반 공격은 무효가 되고 불은 유지하지만 해당 턴의 공격 기회는 소모한다.
- 무효 공격으로 전사·수호자 점수를 얻지 않는다.

### 불 → 나무
- 방어 자원: 물
- 방어 성공: 나무 유지, 물 유지, 공격자의 불 1개 소멸
- 방어 실패: 나무 1개 소멸, 공격자의 불 1개 유지

### 불 → 식량
- 방어 자원: 돌
- 방어 성공: 식량 유지, 돌 유지, 공격자의 불 1개 소멸
- 방어 실패: 식량 1개 소멸, 공격자의 불 1개 유지

> 방어 자원은 소모하지 않는다.

## 7. 가축 유지
- 가축 1개당 나무 1개 + 식량 1개가 필요
- 유지에 필요한 자원이 부족하면 유지 가능한 수만 생존하고 초과 가축은 사라진다.
- 예: 가축 3, 나무 2, 식량 3 → 가축 2 생존, 1 소멸
- 정확한 유지 판정 시점은 별도 결정 사항

## 8. 점수 카드 시장
### 2–3인
- 1점 카드 3장
- 2점 카드 2장
- 3점 카드 1장
- 총 6장 공개

### 4–6인
- 1점 카드 4장
- 2점 카드 3장
- 3점 카드 2장
- 총 9장 공개

카드가 구매되면 같은 점수 등급의 카드로 교체한다.
자원 획득 이후 한 턴에 최대 1장을 구매할 수 있으며 구매는 선택 사항이다.

### 베타용 임시 덱
- 1점 15장, 2점 15장, 3점 10장: 총 40장으로 비용 조건을 검증한다.
- 자원 종류를 순환한 대칭 비용 패턴과 재현 가능한 시드 셔플을 사용한다. 최종 카드 목록/배분은 아니다.
- 해당 등급의 공급 덱이 소진되면 그 자리는 비워 둔다. 재순환이나 다른 등급 대체는 하지 않는 베타 구현이며, 최종 소진 규칙은 별도 확정한다.
- 3점 구매 시 비공개 스킬 덱에서 1장을 즉시 지급한다. 베타 스킬 덱이 소진되면 구매는 정상 처리하고 보상을 수령 대기로 기록한다.

## 9. 점수 카드 비용
### 1점 카드
- 단일 자원: 총 4개
- 복수 자원: 총 5개
- 복수 자원은 2–3종 조합을 기본으로 한다.

### 2점 카드
- 2종 자원: 총 7개
- 3–4종 자원: 총 8개

### 3점 카드
- 3–4종 자원
- 총 10개
- 구매 시 스킬 카드 1장 획득

## 10. 스킬 카드
- 종류는 본인만 확인하고 보유 장수는 모두에게 공개한다. 별도 보유 한도는 없으며 토큰 15개 한도에도 포함하지 않는다.
- 모든 스킬은 사용한 카드 1장을 소모한다.
- 베타 임시 구성은 공격/방어/훔쳐보기/공개 각 5장, 총 20장이다. 최종 배분이 아니며 테스트 후 변경한다.
- 일반 공격을 먼저 실행하거나 생략한 뒤 본인 턴 중 스킬을 사용할 수 있다. 스킬을 먼저 쓰면 턴 시작의 일반 공격을 생략한 것으로 처리한다.
- 획득 전/후, 구매 후 모두 사용 가능하며 새로 받은 카드도 즉시 사용 가능하다. 턴당 스킬 사용 횟수 제한은 없다.

### 공격
- 불 없이 일반 공격과 별개로 사용한다.
- 기본 자원 5종과 가축 중 지정한 종류의 토큰 1개를 제거한다. 공개분부터 차감한다.
- 물·돌의 자동 방어는 무시한다.
- 대상 토큰이 없으면 무효이며 공격 스킬 카드 1장만 소모한다. 다른 대상으로 전환하지 않는다.

### 방어
- 자동 사용하지 않는다. 피격자가 사용 여부를 선택한다.
- 일반 공격은 대상 토큰 존재 여부를 먼저 검사한다. 나무가 없으면 물이 있어도 무효다.
- 일반 공격은 물·돌로 먼저 자동 방어하고, 방어 수단이 없을 때만 방어 스킬을 선택할 수 있다.
- 공격 스킬도 방어 스킬로 막을 수 있다. 가축을 포함해 모든 토큰을 보호한다.
- 방어 스킬을 사용하면 카드 1장을 소모하고 피해를 막는다. 일반 공격을 막았다면 공격자의 불 1개도 소모한다.
- 사용하지 않으면 피해를 적용하고 방어 스킬은 유지한다.
- 공격 또는 방어에 스킬이 사용된 해당 공격에서는 전사·수호자 모두 점수를 얻지 않는다.
- 방어 응답을 기다리는 동안 다른 행동이나 턴 종료를 허용하지 않는다.

### 상대 은닉 토큰 전체 훔쳐보기
- 지정한 상대의 현재 은닉 토큰 전체 구성을 시전자에게만 보여준다.
- 토큰의 공개/은닉 상태는 바뀌지 않는다. 이후 재고 변화가 자동으로 보이는 효과는 아니다.

### 상대 은닉 토큰 1개 공개
- 시전자가 상대의 가려진 토큰 자리 하나를 선택한다. 종류를 지정하지 않는다.
- 토큰 종류를 알 수 없도록 엔진에서 무작위로 배치한 것과 같은 확률로 한 개를 뽑는다.
- 뽑힌 1개를 공개 재고로 옮겨 모두에게 보여준다. 총 토큰 수는 변하지 않는다.
- 훔쳐보기와 공개 효과는 방어 스킬로 막지 않는다.
- 베타에서는 상대의 은닉 토큰이 0개이면 정보 스킬 사용 요청을 거부하며 카드를 소모하지 않는다.

## 11. 부족장
게임 시작 시 각 플레이어는 부족장 1명을 가진다. 별도의 캐릭터 시스템은 사용하지 않는다.

현재 설계된 부족장 유형:
- 전사: 성공한 공격 1회당 +1점
- 수호자: 성공한 방어 1회당 +1점
- 목축 부족장: 가축 2개 이상을 2턴 연속 유지하면 +1점. 점수 획득 후 연속 유지 카운터 초기화
- 자원 특화 부족장: 해당 자원이 구매한 점수 카드 비용에 누적 6개 등장할 때마다 +1점
- 1점 카드 부족장: 1점 카드 3장 획득마다 +1점
- 2점 카드 부족장: 2점 카드 2장 획득마다 +1점
- 3점 카드 부족장: 3점 카드 1장 획득마다 +1점

자원 특화 부족장은 불/물/돌/나무/식량별로 설계할 수 있다.

## 12. 승리 조건
- 한 플레이어가 15점에 도달하면 현재 라운드를 마친 후 최고 점수 플레이어가 승리한다.
- 동점 처리 규칙은 미정

## 13. 기본 턴 구조
1. 턴 시작
2. 선택적 공격(최대 1회)
3. 자원 획득
4. 필요한 자원 정보 공개
5. 점수 카드 구매
6. 가축 유지 판정
7. 부족장 보너스 판정
8. 보유 한도 15개 적용
9. 턴 종료

## 14. 미정 사항
- 가축 유지 판정의 정확한 시점
- 베타 스킬 덱의 최종 종류/배분 및 소진 보상 처리
- 은닉분의 카드 구매 비용 사용 시 공개 정보 범위(방어 토큰 1개 공개 전환은 확정)
- 부족장 선택/배정 방식
- 부족장 보너스 최대치 여부
- 동점 처리
- 최종 카드 덱 구성/카드 수 및 덱 소진 처리
- 정확한 게임 종료 라운드 처리
